# Convergence-Depth Study

This study decides whether the future L4 SA parametric/GNN dataset can stop before `10000` SIMPLE iterations.

The analysis compares cutoffs:

```text
3000, 5000, 7000, 8000, 10000
```

The `10000` result is treated as the reference. New convergence-depth cases use:

```foam
endTime       10000;
writeInterval 1000;
purgeWrite    0;
```

`purgeWrite 0` is used only here so intermediate fields are retained for cutoff checks. The production parametric dataset should use `purgeWrite 1` or `2`.

## Cases

Existing AoA validation anchors are listed in `cases.csv` but not regenerated:

```text
anchor_aoa_0   AoA=0,  Re=6e6
anchor_aoa_10  AoA=10, Re=6e6
anchor_aoa_15  AoA=15, Re=6e6
```

New cases generated by `makeConvergenceCases.py`:

```text
cd_000  AoA=-4, Re=3e6
cd_001  AoA=12, Re=3e6
cd_002  AoA=16, Re=9e6
```

## Generate Cases

```bash

```
