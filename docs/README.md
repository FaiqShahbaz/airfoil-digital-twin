# Documentation

The project has two canonical manuals, read in sequence:

1. [../CFD_WORKFLOW.md](../CFD_WORKFLOW.md)
2. [../GNN_WORKFLOW.md](../GNN_WORKFLOW.md)

This directory contains only supporting material:

```text
docs/
├── assets/
│   ├── cfd/       tracked plots, diagrams and representative flow image
│   └── gnn/       graph/data/training diagrams
├── evidence/      current manifest, provenance, hashes and source revision
└── archive/       superseded protocols, audits and runbooks
```

Archived files are retained for historical traceability. They are not the
active instructions and may describe an earlier dataset or open validation
gate. New scientific and operational guidance belongs in one of the two
canonical manuals rather than a new standalone narrative document.
