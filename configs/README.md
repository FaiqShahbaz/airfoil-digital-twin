# Configs

This directory stores lightweight, source-controlled configuration files for dataset conversion, model training, evaluation, and digital-twin runtime behavior.

## Layout

```text
configs/
├── datasets/        # Dataset paths, manifests, tensor contracts, normalization paths
├── experiments/     # Model-family training and evaluation configs
└── digital_twin/    # Runtime surrogate and dashboard-facing configs
```

## Policy

Configs should describe reproducible behavior, not store generated data. Do not place checkpoints, graph tensors, solver outputs, or large manifests here.

Dataset configs may point to ignored CFD exports generated by `cfd/naca0012`, but this repository should not commit raw production cases or large generated artifacts.
