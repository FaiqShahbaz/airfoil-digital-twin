# Airfoil Digital Twin

A local-first airfoil CFD surrogate / digital twin project using Docker-based OpenFOAM workflows, PyTorch/PyTorch Geometric for later-stage modeling, and Streamlit for a later-stage dashboard.

## Scope

This repository is currently at Gate 1: minimal NACA 4-digit geometry generation and environment checks only. It does not yet implement SDF generation, OpenFOAM/STL export, CFD execution, preprocessing, ML training, evaluation, or dashboard functionality.

## OpenFOAM

OpenFOAM will be used through Docker, not through a native macOS installation. The environment check only attempts an OpenFOAM Docker run when `OPENFOAM_DOCKER_IMAGE` is configured.

## Validation-First Plan

The first CFD validation step should use one or two airfoils before any broad dataset generation. This keeps the workflow focused on reproducibility, solver configuration, mesh quality, and result sanity before scaling.

## Benchmarking

Initial benchmarking should be internal only, using held-out local OpenFOAM cases generated by the project workflow. Literature comparisons should happen only after source and protocol verification.

No ML4CFD-equivalent performance is claimed. No unsupported accuracy, speedup, or runtime targets are claimed.

## Gate 0 Setup

Install minimal early dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the environment check:

```bash
python scripts/check_environment.py
```

Run tests:

```bash
python -m pytest
```
